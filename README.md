I work hands-on across the entire product - from analyzing business requirements and translating them into actionable tickets, to architecture and user experience, clean and testable code, cloud deployment, and leading engineering teams.

Recently, I have been focused on **AI Engineering & Automation**, building my own projects to save time, connect systems and automate workflows:

**[Vibe iOS app](https://aleksanderfigiel.pl/vibe-ios-app/)** turns prompts into iOS apps delivered to an iPhone through TestFlight, automating repository setup, AI coding and builds. I built it with TypeScript, Supabase, GitHub Actions and Swift, connecting the workflow with a GitHub Copilot coding agent. Users do not need their own paid Apple Developer account until they publish to the App Store.

**[AI Email Router](https://email-router-kazjmyztga-ew.a.run.app/)** classifies emails and forwards them to the right department using editable routing rules, tool calling and SMTP integration. I built a [Next.js, React and TypeScript app](https://github.com/feegloo/agent-email-router-next) with a live routing visualization, alongside the original [Python implementation using Pydantic AI](https://github.com/feegloo/agent-email-router), both powered by models served through Ollama.

**[ChatRAG](https://chatrag.app/)** answers questions about uploaded files using RAG, with document summaries and suggested prompts. I built the Python engine with FastAPI, LangChain, ChromaDB and the OpenAI API, with Vue.js, Node.js, PostgreSQL, Docker and GCP. ([GitHub](https://github.com/feegloo/chatrag-app)).
